# FastAPI 用户认证与管理服务

> 一个基于 FastAPI + JWT 的 RESTful API 服务，支持用户注册、登录、信息管理、密码修改、点赞等功能。

---

## 🚀 技术栈

- **Web框架**：FastAPI
- **认证方式**：JWT（python-jose）
- **数据校验**：Pydantic v2
- **数据库**：PostgreSQL + SQLAlchemy（异步/同步）
- **密码加密**：bcrypt（passlib）
